# Heart-Risk-Predictor 🫀🤖

An AI-powered web application built with Flask, Machine Learning, and SQL to evaluate heart disease risk from clinical input parameters with prediction history tracking.

## ✨ Features
- 📊 **AI-Based Risk Assessment:** Utilizes trained machine learning models to predict heart disease risk accurately.
- 📁 **Prediction History:** Saves past predictions in a database so users can track and view history details anytime.
- 🎨 **Modern Web Interface:** Clean and responsive UI built for smooth user experience.

## 🚀 Tech Stack
- **Backend:** Python, Flask, SQLAlchemy
- **Machine Learning:** Scikit-Learn / XGBoost
- **Frontend:** HTML5, CSS3, JavaScript
